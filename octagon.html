Octagon Studio : transformer des statistiques TikTok en décisions

Un outil de stratégie vidéo pour un club de sports de combat : il calcule les KPI, note chaque vidéo par rapport aux habitudes du compte, applique 14 règles de recommandation et fait rédiger l'analyse par Claude. Le projet est en discussion avec un club ; il n'est pas encore utilisé.

01Le problème métier

Un club de sports de combat veut attirer de nouveaux membres grâce à TikTok et Instagram Reels. Les statistiques existent, dans TikTok Studio et Meta Business Suite, mais personne n'a le temps de les transformer en décisions : quoi publier, quand, avec quel coach, et pourquoi telle vidéo a marché.

Contraintes : un gérant non technique, un usage au téléphone, et un sujet juridique réel, le droit à l'image des personnes filmées, mineurs compris.

02Ce que j'ai construit

  • Import des exports TikTok et Instagram (CSV, Excel), colonnes reconnues automatiquement en français et en anglais, doublons écartés.
  • KPI sur 7, 28 et 90 jours avec variations, engagement par pilier de contenu et par format.
  • Score Algo de 0 à 100, normalisé par la médiane du compte : 50 veut dire « une vidéo normale pour ce compte ». Les pondérations sont réglables.
  • 14 règles de recommandation, chacune avec le constat chiffré, l'hypothèse et l'action proposée.
  • Analyse rédigée par Claude à partir d'un résumé chiffré. Claude écrit, il ne calcule pas : tous les nombres viennent du code. Sans clé API, un repli à base de règles produit le texte : l'outil n'est jamais bloqué.
  • Vérification avant publication, avec blocage si une autorisation de droit à l'image manque.
  • Production : générateur de scripts, calendrier, bibliothèque de 121 accroches et 157 idées.
  • Comptes individuels : administrateur et coachs, droits séparés.

À essayer : la démo interactive reproduit le Score Algo et trois des règles sur un jeu de données fictif, et montre le résumé exact que Claude reçoit.

04Extrait de code

Le cœur du Score Algo. Comparer une vidéo à la médiane du compte, plutôt qu'à des seuils fixes, rend le score utile pour un petit compte local comme pour un gros.

Moteur d'analyse · sous-score d'un signalTypeScript
// r = valeur de la vidéo / médiane du compte ; sub = 100 × r^k / (r^k + 1), k = 1,5
// r = 1 (vidéo médiane) → 50 ; r = 2 → 74 ; r = 0,5 → 26 ; r = 0 → 0
export function subScore(value: number, med: number | null): number {
  if (med == null) return 50;
  if (med <= 0) return value > 0 ? 75 : 50;
  const r = Math.max(0, value) / med;
  const p = Math.pow(r, SCORE_EXPONENT);
  return (100 * p) / (p + 1);
}
// Le Score Algo est la moyenne pondérée des sous-scores (rétention, partages,
// enregistrements, abonnés, commentaires, likes), signaux absents exclus.

05Résultat

Pas encore de résultat d'usage. L'outil n'est pas utilisé par un club : il n'y a donc aucun chiffre d'adoption ou d'impact à montrer. Ce qui est vérifiable aujourd'hui, c'est ce qui est construit.

06Ce que j'ai appris

  • Le modèle rédige, le code calcule. Claude reçoit un résumé chiffré et transforme des constats en conseils lisibles. Il ne peut pas inventer un chiffre, parce qu'il n'en produit aucun.
  • Prévoir la panne de l'IA dès le départ. Chaque appel peut échouer ou être refusé : l'outil bascule alors sur ses règles, sans écran d'erreur.
  • Parler la langue de l'utilisateur. Un gérant de club ne veut pas un « taux d'engagement normalisé » mais « cette vidéo a fait deux fois mieux que d'habitude, refaites ce format ».
  • Démontrer avant d'avoir des utilisateurs. Un jeu de démonstration réaliste permet de discuter du produit avec le club sur du concret, sans toucher à ses données.
